## 作品简介

齐鲁影策是一款面向青年创作者的齐鲁文化 AI 影像创作助手，参加“2026山东省首届大学生AI大模型创新传播大赛——AI传播工具创新赛道”。

作品解决的主要问题是：拍摄后素材难整理、不知道如何组织故事，以及脚本镜头与实际素材对应不清。核心思路是“素材驱动创作”：从真实照片和视频出发，理解画面内容，结合文化知识进行选题与分镜规划，并将镜头绑定到真实素材。

Slogan：让每一帧山东，都有故事可讲。

## 请先阅读：本包是什么

本包包含项目源码、依赖锁定文件、数据库迁移、界面资源、测试代码和运行说明。它不是解压即用的 Windows 软件，也不是已部署的公网网站。老师需要准备开发环境后本地运行，或由作者配合演示。

为保护隐私，本包不含真实 API Key、个人配置、本地数据库、用户上传的照片与视频、缩略图和关键帧。首次启动是空项目，需要自己创建项目并上传测试素材。原电脑的数据没有被删除，只是不放入压缩包。

## 当前功能与限制

- 已实际验证：项目创建、真实素材上传与管理、图片缩略图、视频信息读取、FFmpeg 视频缩略图及代表性关键帧。
- 已实现并通过离线逻辑测试：选题与故事规划接口、分镜编辑与素材绑定、锁定约束、补拍清单、文化依据核验以及 PDF/CSV/TXT/SRT 导出。
- 尚未完成：真实 DeepSeek 的完整端到端验收。当前素材解读存在模型输出不符合字段范围或枚举值、被校验拒绝的问题；因此可能无法进入后续选题和分镜生成。这是已知问题，不应视为已稳定可用。
- 文化知识第一版覆盖济南大明湖、趵突泉和烟台城市/海洋文化，条目规模有限。
- 导出的是创作方案与字幕，不是自动剪辑完成的视频。没有登录系统、云存储或 Premiere 正式集成。
- 无需 API Key 即可体验上传与媒体处理；发起 AI 解读或生成需要自行配置有效且有额度的 Key，并可能产生费用。

## 本地安装与启动（Windows 示例）

根目录新增 `start-qiluvision.cmd`，准备好下述环境后可双击：它会检查环境、安装缺失的前端项目依赖、创建缺失的本地配置、应用数据库迁移，并在服务就绪后打开浏览器。Python 虚拟环境及其依赖仍需按下述步骤准备，不自动安装全局软件。不需要提前手动复制 `.env`；已有配置不会被覆盖。

只检查环境可以在终端执行 `node scripts/start-local.mjs --check`。缺少环境时终端会给出说明。正常启动后请保持终端运行；服务默认仅本机可访问。启动器不会修复下述已知 AI 格式校验问题。

准备 Node.js（建议 22 LTS）、pnpm 11、Python 3.11+、FFmpeg 和 ffprobe。以下是本项目当前运行要求，不含这些软件的安装包。

解压后进入 QiluVision 目录，在终端执行：

```powershell
Copy-Item .env.example .env
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate
python -m venv media-service/.venv
media-service/.venv/Scripts/python.exe -m pip install -e ./media-service
```

在 `.env` 中将 `MEDIA_PYTHON_PATH` 改为当前解压位置下虚拟环境 Python 的完整路径，例如：

```dotenv
MEDIA_PYTHON_PATH=C:/QiluVision/media-service/.venv/Scripts/python.exe
```

请使用自己的真实解压路径，不要原样照抄示例路径。确保 FFmpeg 和 ffprobe 在 PATH 中，或在 `.env` 的 `FFMPEG_PATH` 和 `FFPROBE_PATH` 中填写完整路径。

然后执行：

```powershell
pnpm dev
```

保持终端运行，在同一台电脑浏览器打开 `http://localhost:3000/`。如果终端提示使用了其它端口，以实际打印地址为准。关闭服务后网页将无法访问；本机 localhost 地址不能直接发给其他人作为公网链接。

无需独立启动 Python Web 服务，Next.js 会调用媒体处理 CLI。更多配置见项目根目录 README.md 和 media-service/README.md。

## 使用教程

1. 创建项目，填写名称和一句创作意图，例如“我想讲一个年轻人眼中的大明湖”。
2. 上传图片或短视频。首次建议使用少量小文件；图片支持 JPG、JPEG、PNG、WEBP，单张默认上限 50 MB；视频支持 MP4、MOV，单个默认上限 2 GB。单次最多 20 个文件、合计不超过 2 GB。
3. 等待媒体处理完成，打开素材详情查看图片、视频信息与视频关键帧。这一过程不调用 AI。
4. 如需尝试 AI，在“设置”中填写自己的 DeepSeek API Key。保存只检查格式，不证明 Key 有效或有余额。不应发送私密照片或未经授权的素材给 AI 服务。
5. 进入素材详情的“素材解读 · 影像观察”，点击“开始解读”。只有至少一份素材成功通过校验并保存后，创作工作台的“推荐三个选题”才会启用。当前版本可能在这一步遇到上述已知问题，请勿反复点击以免重复计费。
6. 解读成功后进入“创作方案”，推荐并选择选题，设置画幅、目标时长与镜头数量，再生成故事和分镜。默认竖屏 9:16、60 秒、10 个镜头。
7. 可编辑旁白、替换素材、调整顺序，并锁定要保留的镜头或素材；修改后先保存，再执行重规划。可以诊断缺镜头并加入补拍清单。
8. 核验旁白文化依据，保存方案后导出 PDF、CSV、TXT 或 SRT。文化依据不足时只提示“未在当前知识库中找到充分依据”，不直接判断真假。

步骤 6–8 是已实现的操作流程，不表示当前真实 AI 链路已验收通过。离线测试数据不会显示到用户项目中。
